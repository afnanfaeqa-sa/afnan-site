# موقع مركز أفنان الفائقة

- **لوحة التحكم:** `/admin` على رابط الموقع.
- **التعديلات** من اللوحة بتتحفظ هنا في فولدر `content/`، وCloudflare بيبني الموقع من جديد تلقائيًا خلال دقيقة.

## إعدادات Cloudflare Pages
- Build command: `python3 build.py`
- Build output directory: `dist`

## الفولدرات
- `content/` المحتوى اللي بيتعدّل من اللوحة (الخدمات، المقالات، السلايدر، الآراء، الأسئلة، الأرقام)
- `static/` التصميم والسكريبتات والصور
- `templates/` قالب الصفحة الرئيسية ونصوص الخصوصية والشروط
- `admin/` لوحة التحكم
- `build.py` بيجمّع كل ده في فولدر `dist/`
